# 溱溱有味 · 美食手帳作品集

水彩風格插畫作品集網站，溫馨美食手帳質感。

## 功能

- **前台**：米白色水彩紙張背景、柔和手帳式排版，作品以 4:5 比例展示，點擊可放大查看
- **後台**：密碼登入後可上傳新作品（圖片 + 標題），也可刪除作品

## 啟動方式（請在你自己的電腦上執行）

1. 解壓縮這個資料夾
2. 打開終端機（Terminal / 命令提示字元），進入資料夾：
   ```bash
   cd 溱溱有味作品集   # 或你解壓後的資料夾名稱
   ```
3. 執行：
   ```bash
   python3 server.py
   ```
   （Windows 如果沒有 python3，可試 `python server.py`）

4. 打開瀏覽器訪問：
   - 前台：http://127.0.0.1:5000/
   - 後台：http://127.0.0.1:5000/admin
   - 密碼：`66798961`

## 系統需求

- 已安裝 Python 3.8 或以上（幾乎所有電腦都有）
- 無需安裝任何額外套件

## 資料位置

- 作品圖片：`uploads/`
- 作品資料：`data/works.json`

## 注意

請在你自己的電腦上運行，不要嘗試連線到別人給的 127.0.0.1 位址。
